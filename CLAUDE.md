# CLAUDE.md

This file exists only to point at the real one. **Read
[`AGENTS.md`](AGENTS.md) now, before your first edit.** It is the operating
manual for this repo and it is not loaded automatically.

There is one manual, not two. Nothing that belongs in `AGENTS.md` is copied
here, because two copies drift and the stale one is always the one that gets
believed.

After that: [`docs/platform.md`](docs/platform.md) is the current state of
everything, and the `site-platform`, `cloudflare`, `buttondown`,
`moment-hill-content` and `shifted-knowledge-content` skills carry the
procedures. Skills route themselves; the manual does not.

Two things in `AGENTS.md` are worth knowing before you have read it, because
they are the actions you cannot take back: **do not write prose into a content
repo**, and **do not push a content repo without saying so first** — a push
there is a production deploy. The reasoning for both is in the manual.
